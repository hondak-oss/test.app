# 筋トレ管理アプリ 設計書

- 作成日：2026-11-01
- 状態：レビュー待ち

## 1. 目的

筋トレを始めたばかりの利用者が、YouTube の再生リスト「筋トレ」の動画を見ながらトレーニングし、
その記録（いつ・何回・何分やったか）を残せるようにする。
あわせて、今やっているトレーニングが**体のどこに効いているか**を人体図のアニメーションと説明文で示し、
初心者でも鍛えている筋肉を理解できるようにする。

### 成功の条件

- iPhone の Safari で開け、「ホーム画面に追加」でアプリのように使える
- 6本の動画をアプリ内で再生でき、再生した時間が自動で記録される
- カレンダーでトレーニングした日がひと目で分かる
- 再生中の動画が効く部位が、人体図の上で光り、部位の説明が読める
- 一通りモードで、休憩をはさみながら6本を順番にこなせる

### 利用者と前提

- 利用者は本人ひとり。ログイン・同期はしない
- 記録は iPhone 本体（ブラウザの localStorage）にだけ保存する
- 基本の使い方は「6本を一通り、週3回、間に休みの日を入れる」

## 2. 作らないもの

- 動画の追加・編集画面（動画は `js/videos.js` に直接書く）
- ログイン、サーバー、データ同期
- 通知・リマインダー
- きつさメモ、体重記録（使ってみてから検討）

## 3. 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルド作業なし）
- JavaScript は ES Modules（`<script type="module">`）で役割ごとにファイルを分ける
- 動画再生は YouTube IFrame Player API（`playsinline=1` で iPhone でも画面内再生）
- 公開は GitHub Pages（リポジトリ `hondak-oss/test.app`）
  - 無料で使うにはリポジトリを Public にする必要がある。**公開作業の直前に本人に確認する**
- `manifest.json` とアイコンで、ホーム画面追加時の名前とアイコンを設定
- Service Worker（オフライン対応）は入れない。動画再生にネット接続が必須のため

### 4.3 記録（localStorage キー `kintore.v1`）

```json
{
  "records": [
    { "id": "r_1730440000000", "date": "2026-11-01", "videoId": "core5", "seconds": 298 }
  ],
  "settings": { "weeklyGoal": 3, "restSeconds": 60 }
}
```

- `date` は端末の現地時刻での `YYYY-MM-DD`
- `seconds` は実際に再生していた秒数（一時停止中・休憩中は含まない）
- 保存データが無い・壊れている場合は空の記録と初期設定で始める

## 5. 記録と集計のルール

- **記録のタイミング**：動画が最後まで終わったとき、または「完了」ボタンを押したとき
- **30秒未満は記録しない**（誤操作対策）。その場合「30秒以上で記録されます」と表示
- 途中でアプリを閉じた・別の動画に切り替えた場合、その動画は記録しない
- **動画の回数**：記録の件数。同じ日に同じ動画を2回やれば2回
- **トレーニング日数**：記録がある日付の数。カレンダーの印は1日1つ
- **週の目標**：その週（**月曜はじまり**）のトレーニング日数で数える。初期値は週3日。1〜7日で変更可
  - 一通りで6本やっても、その日は「1日」と数える
- **連続日数**：今日から過去に向かって、記録のある日が何日続いているか。
  今日まだ記録がなくても、昨日に記録があれば昨日から数える（途切れていない扱い）
- **前回からの日数**：各動画カードに「前回：今日／昨日／N日前／まだ」と小さく表示する（目立つおすすめ枠は作らない）

## 6. 画面

画面下に3つのタブ：**トレーニング／カレンダー／記録**。

### 6.1 トレーニング

- 上部：今週の進み具合（例「今週 2/3日」）と連続日数
- 「一通りスタート」ボタン（大きめ）
- 6本の動画カード：サムネイル、タイトル、目安時間、メイン部位の呼び名、前回からの日数
- カードをタップ → 再生画面（1本だけ再生）

### 6.2 再生画面（1本 / 一通りモード共通）

- 上：YouTube プレーヤー
- 中：再生時間（実際に再生した時間）と「完了」ボタン
- 下：人体図（前・後ろを横に並べる）
  - メイン部位：オレンジではっきり、ゆっくり明滅（約2秒周期）
  - サブ部位：同じ色で薄く明滅
  - 対象外の部位：グレー
- その下：部位の説明カード（正式名・呼び名・説明文）。メイン部位を先、サブ部位を後に並べる
- 端末の「視差効果を減らす」設定がオンなら明滅を止め、色だけで示す

### 6.3 一通りモード

1. 「一通りスタート」で 1本目を再生
2. 1本終わる（または「完了」）と記録し、休憩画面へ
3. 休憩画面
   - 大きなカウントダウン（設定の休憩時間、初期60秒）
   - 「次はこれ」：次の動画のタイトルと、その部位を光らせた人体図
   - 「+30秒」ボタン、「スキップ」ボタン
   - 残り3秒から短いビープ音（Web Audio API）
4. 休憩が終わると次の動画を自動再生する。iPhone の制限で自動再生できない場合は大きな「再生」ボタンを出す
5. 6本終わったら完了画面：「おつかれさまでした！」、今日の合計時間、今週の進み具合（目標達成ならお祝い表示）
6. 「やめる」ボタンでいつでも中断できる。終わった動画の分は記録済み
7. 30秒未満で終わった動画は記録せず、そのまま休憩に進む

### 6.4 カレンダー

- 月表示（月曜はじまり）、前月・次月へ移動できる
- トレーニングした日に印、今日の日付を強調
- 日付をタップ → その日の動画一覧と合計時間

### 6.5 記録

- 合計トレーニング日数、合計の動画回数、合計時間、連続日数、最長の連続日数
- 動画ごとの回数と時間
- 部位ごとの回数（メイン部位として鍛えた回数）
- 設定：週の目標（1〜7日）、休憩時間（30・60・90秒）
- バックアップ：
  - 「書き出す」：JSON ファイル `kintore-backup-YYYY-MM-DD.json` を保存
  - 「読み込む」：ファイルを選び、確認ダイアログのあと**今の記録を置き換える**

### 6.6 見た目

- ダーク背景＋オレンジのアクセントカラー
- 文字・ボタンは大きめ（ボタンの高さ 44px 以上）
- iPhone の画面幅（375〜430px）を基準にし、ノッチ・ホームバーの余白（safe-area）を確保する

## 7. エラー時の動き

| 状況 | 動き |
|---|---|
| YouTube を読み込めない | 「動画を読み込めませんでした。電波の良い場所で再度お試しください」と表示。他の画面は使える |
| localStorage が使えない（プライベートモード等） | 画面上部に「記録が保存できません」と警告。再生とアニメーションは使える |
| 読み込んだバックアップが壊れている・形式が違う | エラーを表示し、今の記録は一切変更しない |

## 8. テスト

- `node --test` で `js/stats.js` と `js/storage.js` を自動テストする（追加のライブラリ不要）
  - 30秒未満を記録しないこと
  - 週の進み具合（月曜はじまり、日数で数える、週をまたぐ場合）
  - 連続日数（今日あり／今日なし昨日あり／途切れ）、最長連続日数
  - 前回からの日数の表示文字列
  - 動画別・部位別の集計
  - バックアップの書き出し → 読み込みで元に戻ること、壊れたデータを拒否すること
- 画面は Chromium（Playwright）の iPhone サイズで開き、タブ切り替え・カレンダー・記録画面・休憩画面の動作とスクリーンショットで確認する
- YouTube 再生と自動再生の挙動は実機の iPhone で本人に確認してもらう
