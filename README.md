# 筋トレ記録

YouTube の筋トレ動画を見ながらトレーニングして、記録を残すための iPhone 向け Web アプリです。

- 動画をアプリの中で再生し、**実際に再生した時間**を自動で記録
- 今やっているトレーニングが**どの筋肉に効いているか**を人体図のアニメーションと説明で表示
- **一通りモード**：6本を順番に再生。動画の間に休憩（カウントダウン・ビープ音つき）
- **カレンダー**：トレーニングした日に印
- **記録**：回数・時間・連続日数・動画ごと・部位ごとの集計、週の目標、バックアップ

記録は iPhone 本体（ブラウザ）にだけ保存されます。ログインやサーバーはありません。

## iPhone での使い方

1. Safari で公開 URL を開く
2. 画面下の共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面のアイコンから開くと、普通のアプリのように使えます

> 記録はこの iPhone の中にだけ保存されます。ときどき「記録」タブの「書き出す」でバックアップしておくと安心です。

## 動画を追加するには

`js/videos.js` の `VIDEOS` に 1 件追加します。

```js
{
  id: 'squat',                // アプリ内で使う名前（英数字・重複しない）
  youtubeId: 'xxxxxxxxxxx',   // YouTube の URL の v= の後ろ
  channel: 'チャンネル名',
  durationLabel: '3分',        // 表示用の目安時間
  title: '動画のタイトル',
  main: ['glutes'],           // メインで効く部位（MUSCLES の id）
  sub: [],                    // サブで効く部位
},
```

部位の id は同じファイルの `MUSCLES` にあります。脚の部位など、新しい部位を足すときは `MUSCLES` に追加し、人体図に描く場合は `js/body.js` の `FRONT` / `BACK` に図形を足してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/videos.js` | 動画と部位のデータ |
| `js/storage.js` | 記録の保存とバックアップ |
| `js/stats.js` | 回数・時間・連続日数などの計算 |
| `js/calendar.js` | カレンダーのマス目の計算 |
| `js/session.js` | 一通りモードの進行 |
| `js/player.js` | YouTube 再生と時間の計測 |
| `js/body.js` | 人体図 |
| `js/views/*.js` | 各画面 |
| `js/app.js` | 画面の切り替え |

## 開発

ビルドは不要です。

```sh
# ローカルで動かす
python3 -m http.server 8000
# → http://localhost:8000/

# テスト（Node.js 20 以上）
npm test
```
